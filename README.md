## 🛠 Technologies Utilisées

### **Backend**
- Symfony 6.4 (Framework PHP MVC)
- Doctrine ORM 2.17 (Base de données)
- EasyAdmin Bundle 4.10 (Interface d'administration)
- PHP 8.1+

### **Frontend**
- Twig 3.0 (Moteur de templates)
- CSS3 (Variables CSS, Flexbox, Grid, Media Queries)
- JavaScript ES6+ (Modules, async/await, Touch Events API)
- AOS 2.3.1 (Animations scroll)
- jQuery 3.5.1

### **Sécurité & Intégrations**
- reCAPTCHA v3 (Protection anti-spam)
- Stripe PHP SDK 14.6 (Paiements)
- Calendly Widget (Prise de rendez-vous)
- Symfony Security Bundle (Authentification)

### **Services & Analytics**
- Symfony Mailer (Google Mailer, Mailgun)
- Système Analytics Personnalisé RGPD conforme
- Cookie Consent Banner personnalisé
- Analytics Dashboard (Interface admin)

### **Outils**
- Composer (Gestion dépendances)
- Git (Versioning)
- YAML (Configuration)
- Symfony Console (Commandes personnalisées)
