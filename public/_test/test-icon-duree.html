TEST ICÔNE DURÉE -

Durée de formation

Si tu vois une icône bleue avec une horloge blanche et une bordure blanche, ÇA MARCHE !

Si tu vois juste un carré vide ou blanc, c'est le CSS qui n'est pas chargé.

Pour tester :

  1. Ouvre cette page : https://dev.infpf.fr/test-icon-duree.html
  2. Ouvre les DevTools (F12)
  3. Regarde l'onglet "Network" pour voir si fichier-v2.min.css est chargé
  4. Regarde l'onglet "Elements" pour voir si le SVG est bien là
