Exclusion du trafic administrateur

Votre trafic peut être exclu des statistiques de plusieurs manières, par ordre de priorité :

1. Exclusion automatique par rôle

Déjà actif : Si vous êtes connecté avec le rôle ROLE_ADMIN, votre trafic est automatiquement exclu. Aucune configuration n'est nécessaire.

2. Exclusion des routes privées

Déjà actif : Toutes les pages administratives sont automatiquement exclues.

Routes exclues par défaut :

  • /admin/*
  • /backoffice/*
  • /dashboard/*
  • /api/*
  • /_profiler/*
  • /_wdt/*

3. Cookie développeur (opt-out permanent)

Pour bloquer complètement le tracking sur votre navigateur, utilisez les commandes suivantes dans la console JavaScript :

Activer le blocage permanent

// Ouvrez la console du navigateur (F12) window.INFPFAnalytics.setDevCookie(); // Le cookie xeilos_dev=1 sera créé // Il bloquera tout tracking de manière permanente

Désactiver le blocage

// Pour réactiver le tracking window.INFPFAnalytics.removeDevCookie();

4. Exclusion par adresse IP publique

Étape 1 : Trouver votre IP publique

  1. Accédez à whatismyip.com
  2. Copiez votre adresse IP publique (exemple : 203.0.113.45)
Important : L'adresse 192.168.1.119 est une IP privée/locale et n'est PAS visible côté serveur. Utilisez uniquement votre IP publique.

Étape 2 : Configuration

Éditez le fichier config/analytics_config.php :

'excluded_public_ips' => [ '203.0.113.45', // Remplacez par VOTRE IP publique // Ajoutez d'autres IPs si nécessaire ],

Comportement RGPD

Le système respecte strictement les réglementations RGPD et CNIL avec deux modes de fonctionnement distincts.

Mode "Tout refuser" (Anonyme strict)

Conformité maximale - Aucune donnée personnelle collectée :

  • Aucun cookie non essentiel
  • Aucun identifiant de session
  • Aucune adresse IP stockée
  • Aucun fingerprinting
  • Pas de tracking individuel
  • Agrégation locale uniquement

Mode "Tout accepter" (Conformité RGPD)

Tracking conforme avec données anonymisées :

  • ID de session aléatoire (pas de PII)
  • IP anonymisée (dernier octet masqué)
  • Pays uniquement (géolocalisation serveur)
  • Type d'appareil, OS et navigateur
  • Langue du navigateur
  • Source de trafic (referrer)
  • Paramètres de campagne (UTM)
  • Pages visitées et durée
  • Profondeur de défilement
  • Interactions avec éléments clés
Données jamais collectées : Email, nom, téléphone, adresse IP complète, ville précise, ou toute autre information personnellement identifiable (PII).

Vérification des exclusions

Méthode 1 : Console du navigateur

Ouvrez la console JavaScript (touche F12) et exécutez :

window.INFPFAnalytics.getState();

Résultat attendu si vous êtes exclu :

{ isExcluded: true, excludeReason: "admin_role" // ou "private_path", "dev_cookie" }

Méthode 2 : Dashboard analytics

  1. Accédez au dashboard : /admin/analytics
  2. Vérifiez que votre navigation n'apparaît PAS dans les statistiques
  3. Si vos pages sont visibles, l'exclusion n'est pas active

Méthode 3 : Page de diagnostic complète

Pour une vérification exhaustive de tous les critères d'exclusion (admin, IP, environnement) :

Accéder à la page de diagnostic

Configuration avancée

Personnalisez le comportement du système en éditant config/analytics_config.php :

Ajouter des routes privées personnalisées

'private_paths' => [ '/^\/admin/', '/^\/backoffice/', '/^\/mon-espace-prive/', // Votre route personnalisée ],

Exclure des sous-domaines de test

'excluded_subdomains' => [ 'dev', 'staging', 'preprod', 'test-monsite', // Votre sous-domaine de test ],

Créer une liste blanche de pages publiques

'allowed_public_paths' => [ '/^\/formation/', '/^\/metiers/', '/^\/blog/', '/^\/$/', // Page d'accueil uniquement ],

Commandes utiles

Console JavaScript (navigateur)

Commande Description
window.INFPFAnalytics.getState() Afficher l'état complet du système de tracking
window.INFPFAnalytics.setDevCookie() Activer le mode développeur (bloque tout)
window.INFPFAnalytics.removeDevCookie() Désactiver le mode développeur
window.INFPFAnalytics.revoke() Révoquer le consentement utilisateur

Serveur PHP (développement)

# Afficher les logs de tracking en temps réel tail -f var/log/dev.log | grep Analytics

Checklist de vérification

Assurez-vous que tous les points suivants sont validés :

  • Connecté en administrateur → pas de tracking
  • Accès aux routes /admin/* → pas de tracking
  • Cookie xeilos_dev=1 actif → pas de tracking
  • Mode "Tout refuser" → aucun cookie, aucune donnée individuelle
  • Mode "Tout accepter" → données collectées avec IP anonymisée
  • Dashboard analytics → le trafic administrateur n'apparaît pas

Support technique

Si votre trafic apparaît dans les statistiques

Suivez ces étapes de diagnostic :

  1. Vérifiez que vous êtes bien connecté avec le rôle ROLE_ADMIN
  2. Videz le cache du navigateur (Ctrl+Shift+Delete)
  3. Ouvrez la console et exécutez : window.INFPFAnalytics.getState()
  4. Si isExcluded: false, activez le cookie : window.INFPFAnalytics.setDevCookie()
  5. Rechargez la page et vérifiez à nouveau

Diagnostic approfondi

Si le problème persiste, vérifiez les points suivants :

  • Le fichier config/analytics_config.php est bien chargé
  • Le service AnalyticsExclusionService est correctement injecté
  • Consultez les logs serveur pour voir si les exclusions sont appliquées
  • Vérifiez la configuration Symfony dans config/services.yaml
